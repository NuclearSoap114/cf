Each group should contain at most $$$2$$$ balls, and no more than $$$1$$$ ball of each color.</p><p>Consider all $$$2^n$$$ sets of colors. For a set of colors, let's denote its <span class="tex-font-style-it">value</span> as the minimum number of groups the balls of those colors can be distributed into. For example, if there are three colors with $$$3$$$, $$$1$$$ and $$$7$$$ balls respectively, they can be combined into $$$7$$$ groups (and not less than $$$7$$$), so the value of that set of colors is $$$7$$$.</p><p>Your task is to calculate the sum of <span class="tex-font-style-it">values</span> over all $$$2^n$$$ possible sets of colors.
